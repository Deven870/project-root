## 🚨 EMERGENCY PROCEDURES

### Trade Execution Fails

```
Problem: Dashboard shows 70% but trade loses immediately

Solution:
1. Stop trading (Ctrl+C in terminal)
2. Check: Was model prediction correct?
3. Check: Was entry price correct?
4. Check: Was stop loss hit correctly?
5. Document issue
6. Try again tomorrow
```

### Accuracy Suddenly Drops Below 50%

```
Problem: Day 2-3 accuracy only 40%

Solution:
1. PAUSE trading (stop new entries)
2. Run: python test_dashboard_integration.py
3. Check: Are data feeds working?
4. Check: Did market regime change?
5. Wait 1-2 days for model recalibration
6. Resume when confidence > 65% again
```

### Paper Trading Account Shows Errors

```
Problem: Account value showing ₹0 or negative

Solution:
1. Stop all trades
2. Run: python start_paper_trading.py (reset)
3. Verify: Account resets to ₹250,000
4. Check losses should still be tracked
5. Never lose prior data
```
