## 📞 GETTING HELP

### If Predictions Not Appearing
1. Check market hours (9:15 AM - 3:30 PM IST)
2. Verify API is running: `curl http://localhost:8000/health`
3. Check logs for errors
4. Run tests: `python test_live_predictions.py`

### If Dashboard Won't Load
1. Ensure API is running on port 8000
2. Check Streamlit is installed: `streamlit --version`
3. Try: `streamlit run dashboard.py --logger.level=debug`

### If WebSocket Not Connecting
1. Verify API server is running
2. Check firewall isn't blocking port 8000
3. Try HTTP fallback: `/api/v1/live/predictions`
